Applications on the chip

Three problems that don't look like neural networks at all, each rewritten as matrix multiplies and run on the cycle-exact TinyTPU model (the same one the Verilog is checked against). Change the inputs and the chip runs again.

Image filtering

Click pixels to paint (dark → mid → bright). Every 3 × 3 window becomes one row of a matrix ("im2col"); four filters become four columns. One program, 64 windows, 4 filters.

Quantum search (Grover)

A 2-qubit quantum computer's state is 4 numbers, and every gate is a 4 × 4 matrix. Pick which answer the oracle secretly marks: one Grover step always finds it.

Triangles in a graph

Click one node, then another, to add or remove an edge. The chip computes A² (2-step walks) and A³; triangles = trace(A³) ÷ 6.

A²: number of 2-step walks from row node to column node
A³ (diagonal outlined: 2 × triangles through each node)
