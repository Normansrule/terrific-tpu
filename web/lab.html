Live lab. Run the experiments yourself.

Three experiments that run in your browser on the cycle-exact models of both chips (the same models make jscheck checks against the Verilog on every commit). Change a parameter, press run, and watch the data arrive.

Experiment A

Does batching pay off?

A 16-deep matrix multiply as four accumulated weight tiles, each streaming M vectors. Utilization = useful multiply-accumulates ÷ (16 multipliers × cycles).

Press run.
Experiment B

Is v2 always faster, and always right?

Random programs, with the same dependency-heavy generator as make fuzz, run on both chips. Every pair must end with identical memories; the chart counts how much faster v2 was.

Press run.
Experiment C

What does one scheduling trick buy?

The compiler's hoist option moves each ACT after the next LDW. Same network (8 → 12 → 8 → 4), batch sizes 2 to 48, on v2: plain schedule vs hoisted.

Press run.
