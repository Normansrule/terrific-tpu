Compile a network. Watch it run.

Describe a small neural network and this page does what XLA or TVM does for a real TPU: it tiles every weight matrix into 4 × 4 pieces, finds a home for every tensor in the chip's memories, schedules the instructions, and calibrates each layer's shift. Then it runs the program on the cycle-exact chip model and checks the answer.
